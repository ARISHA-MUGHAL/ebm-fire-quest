# Fire Quest

A buildless, responsive fire-safety learning game. 15 questions, 15 learning cards, 30 original code-drawn SVG pictures, optional sound and a final answer review.

## Hosting
Serve index.html with config.js, data.js, art.js, app.js and style.css. GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

## Private results
1. Create/import a private Google Sheet with the Results template headers below.
2. Open script.google.com, create a project, and paste collector.gs.
3. Set SETTINGS.sheetId to the private Sheet ID. Set SETTINGS.origin to your exact game origin, without a trailing slash. Never publish your Sheet or enable public link access.
4. Run setup and review Google's authorization request. Deploy as a Web app, executing as yourself, with access Anyone. This permits submissions, not reading the Sheet.
5. Put the /exec deployment URL in config.js collectorUrl. Upload config.js and test one synthetic submission before inviting employees.

Headers: Received (UTC), Name, Email, Department, Points, Correct, Total, Accuracy, Seconds, Attempt ID, Campaign, Answer indices.

## Scoring and reporting
Each correct answer earns 100 points; speed has no effect. Server recalculates score from the submitted 15 answer indices. Sheet rows sort by points descending and received time ascending. Ties have equal scores. First submission per self-declared email and campaign is retained. Retrying the same attempt is safe. There is no public leaderboard and no public API for reading employee records. Staff identity is self-declared, not email-authenticated.

## Limitations
This is a learning refresher, not a secure exam. The public source contains the questions and answer key. Identity is not verified; a person could enter another email. No anti-cheating claims are made. The collector is publicly callable; keep its Sheet private, monitor unexpected submissions and disable the deployment when training ends. Apps Script's free quotas apply; it is designed for the requested small cohort, not unlimited traffic. It records completed submissions only; it cannot identify employees who never start without a separate roster.

If delivery cannot be confirmed, the game shows a retry button and lets the participant download their result. It never claims a submission succeeded without an acknowledgement. Registration details stay in memory in the browser; no analytics, third-party images or local-storage identity tracking. Google Fonts is optional; system fonts work if unavailable.

## Content
Company counts, locations and pump settings were supplied by the organiser. Illustrations are not site photographs or maps. Verify company procedures and extinguisher labels before formal training. DCP answer is retained as requested; its learning card clarifies ABC versus BC powder.

Sources: OSHA extinguisher basics; Amerex ABC powder product guidance; Halotron manufacturer; Pennsylvania Office of State Fire Commissioner sprinkler facts; OSHA emergency preparedness. Links are in the game result screen.

## Development
No dependency installation required. Run any static web server in this folder. The source illustrations are original SVG shapes generated by art.js; all 30 question/learning compositions are distinct. Keyboard navigation, reduced-motion support and labelled registration controls are included.
